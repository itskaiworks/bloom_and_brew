# Bloom & Brew

A Flutter-based application developed as part of **ITP 107 – Finals Laboratory Activity 1**. This project demonstrates the application of Flutter and Dart in building a functional and visually organized user interface.

## Overview

Bloom & Brew is a Flutter application created as a practical project for ITP 107. It focuses on applying mobile application development concepts, UI design principles, and Flutter widgets to develop an interactive application.

The project also provides an opportunity to practice organizing application files, managing dependencies, and deploying a Flutter application for web access.

## Technologies Used

- **Flutter** – Application development framework
- **Dart** – Primary programming language
- **Material Design** – UI components and design elements
- **Git & GitHub** – Version control and source code hosting
- **GitHub Pages** – Web deployment
